# VTuber Studio — デモ画面

VRM の 3D モデルを使って AI が解説動画を組み立て、人間がシーングラフを編集して
仕上げるサービスの **デモ画面だけ** を切り出したもの。動作確認と、広告用の
画面収録に使うことを想定している。

音声は **Google Cloud TTS (Neural2 / Wavenet)** を使う。`kit-chatbot` の
`app/api/tts/route.ts` と同じ経路で、API キーも同じものを使い回している。

## 動かす

```sh
npm install
cp .env.example .env     # GOOGLE_TTS_API_KEY を入れる
npm run dev              # ビルドして http://localhost:5175 で配信
```

ブラウザは Chrome 系を想定（WebGL2 と MediaRecorder を使う）。

サーバー（`server.mjs`）が持つのは3つだけ:

- `public/` の配信
- `/api/tts` — Google Cloud TTS のプロキシ。API キーをブラウザに置かないため。
  合成結果は `.cache/tts/` に貯めるので、同じ台詞の2回目以降は API を叩かない
- `/api/save` — ブラウザが録った WebM を受け取り、`out/` に MP4 として保存する。
  変換には同梱の ffmpeg（`ffmpeg-static`）を使うので、別途インストールは要らない

このプロジェクトには2つの画面がある。

| URL | 用途 |
| --- | --- |
| `/` | **スタジオ画面** — 社内・広告収録用。入力・シーングラフ編集・MP4書き出し |
| `/embed` | **デモ体験ウィジェット** — LP に iframe で貼る、訪問者向けの体験版 |

## スタジオ画面（`/`）の流れ

1. 起動すると VRM を読み込み、アバターが待機モーションで動き出す
2. 左の入力欄（動画の概要 / 資料 / 形式）はサンプルで埋まっている
3. **AIで生成** を押すと生成ログが流れ、6カット分の音声が合成され、
   シーングラフが出てきて自動再生が始まる（2回目以降はキャッシュが効いて一瞬）
4. 右のシーングラフで台詞・カメラ・表情・モーションを変えると即座にステージへ反映される
5. 左の **声** を変えると全カットが合成し直される
6. **書き出し** で `out/` に **MP4**（H.264 + AAC / 1280x720 / 30fps）が保存される。
   保存先はボタン下に出て、そのまま **開く** でダウンロードできる

キーボード: `Space` 再生/停止、`F` シネマ表示（UI を隠してステージだけにする）。

## 広告用に収録するとき

- `F` でシネマ表示にすると、ステージと再生バーだけになる
- ウィンドウを 1600x900 前後にしておくとステージが 16:9 でちょうど収まる
- 画面収録は macOS 標準（`Shift+Cmd+5`）で足りる
- 「編集して即反映」を見せるなら、右パネルでカメラを `スライド寄り` → `クローズアップ`
  に切り替えるカットが分かりやすい
- macOS の画面収録はシステム音声を拾わない。**UI の操作は画面収録で、
  完成動画のカットは書き出した MP4（音声つき）で**、と分けて撮るのが確実

## デモ体験ウィジェット（`/embed`）

LP に貼る用に、訪問者が触る部分だけを抜いたもの。シーングラフの編集も
書き出しも持たない。**お題を選ぶ → 作る → 見る** だけで完結する。

```html
<div style="max-width:960px;margin:0 auto;aspect-ratio:16/9;
            border-radius:16px;overflow:hidden;box-shadow:0 24px 60px -24px #0009">
  <iframe
    src="https://<ホスト>/embed"
    style="width:100%;height:100%;border:0"
    title="AI VTuber デモ体験"
    allow="autoplay"
  ></iframe>
</div>
```

- 中身は 16:9 のステージ1枚。文字サイズはすべて `cqw`（ステージ幅基準）なので、
  どのサイズで埋めても見た目の比率が変わらない
- **`allow="autoplay"` は必須。** これが無いと iframe 内で音が出ない
- お題は3つ。選んだお題でちゃんと中身が変わるよう、`src/presets.ts` に
  お題ごとのシーングラフを持たせてある（1本あたり4カット・約25秒）
- 音声は初回だけ合成に数秒かかり、2回目以降はキャッシュで即座に出る

```
  embed.html      デモ体験ウィジェット
  embed.css        〃 のスタイル
  app.js / embed.js  esbuild が吐くバンドル（生成物）
  models/avatar.vrm

  scenegraph.ts   シーングラフ（AI 出力 / 人間が編集する中間表現）と
                  Timeline へのコンパイル。かな→モーラ→口形の変換もここ
  voice.ts        音声合成の呼び出しと再生。再生時刻の基準もここが持つ
  stage.ts        three-vrm のステージ。外部 API は seek(t) のみ
  export.ts       Canvas2D 合成 + MediaRecorder による書き出し
  sample.ts       スタジオ画面のサンプル入力とシーングラフ
  presets.ts      ウィジェットのお題3本
  app.ts          スタジオ画面の配線
  embed.ts        ウィジェットの配線
tools/            npm run check で一括実行できる
  check-presets.mjs say と kana の句読点がそろっているかを検査
  check.mjs        スタジオ画面を通しで確認
  check-embed.mjs  ウィジェットを通しで確認
  check-lipsync.mjs 口パクが実音声に追従しているかを数値で確認
  check-export.mjs 書き出しを実測する
  poses.mjs        各モーションのポーズを撮る

out/              書き出した MP4 の置き場（sample.mp4 が実例）
```

## 設計上の要点

**シーングラフを中間表現に置いている。** AI に動画そのものを作らせるのではなく、
「どのカットで何を喋り、どのスライドを出し、どのカメラで撮るか」を JSON で
吐かせる。人間の修正はこの JSON への編集になるので、反映が即座で、
作り直しもカット単位で済む。

**シーングラフは絶対時刻を持たない。** 尺は合成した音声の実測長から決まる
（まだ合成できていないカットだけ、読みのモーラ数から暫定的に見積もる）。
台詞を書き換えればタイムラインが自動で組み直される。絶対時刻を持つのは
`compile()` が吐く `Timeline` のほう。

**描画は `seek(t)` の純関数。** 待機の揺れも瞬きもカメラ遷移も t だけで決まる。
プレビューのスクラブと書き出しがまったく同じコードを通るので、
「プレビューと書き出しの絵が違う」が原理的に起きない。

**時刻の基準は AudioContext のクロック。** 映像側は毎フレームそれを読んで
seek するので、再生でも書き出しでも音と口パクがずれない。

**口パクは合成音声の実測に貼る。** SSML に句読点ごとの `<mark>` を挿し、
Google TTS が返すタイムポイントを区切りとして、その区間に読みのモーラを
敷き詰める。長い台詞でもズレが溜まらない。読み（かな）を
シーングラフに持たせているのはこのため。

## デモとして割り切っている部分

- **生成が本物の LLM ではない。** `src/sample.ts` / `src/presets.ts` の
  固定シーングラフを、それらしい遅延とログ付きで返している。
  差し替え口はどちらも `generate()` の一箇所
- **ウィジェットの入力はお題の選択だけ。** 自由入力にすると、何を打っても
  同じ動画が出てしまい体験として破綻するため。本番で LLM につなげば自由入力にできる
- **「AIに直してもらう」もキーワード置換。** 本番はこのカットだけを
  LLM に投げ直して差分を受け取る
- **書き出しが実時間録画。** 48 秒の動画に 48 秒（+ MP4 変換 10 秒ほど）かかる。
  本番はヘッドレス Chromium でフレームを 1 枚ずつ撮って ffmpeg で
  結合する想定（`export.ts` の合成規則はそのまま流用できる）
- **モデルは three-vrm のサンプル VRM。** 差し替えは `public/models/avatar.vrm`
